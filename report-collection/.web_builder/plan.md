# 珠宝智慧管理·三大系统需求报告集

## 项目概述
构建一份综合性的HTML报告集，整合三个需求系统的分析：光谱仪数据AI质检、VR手串宝石穿戴、进库存AI管理。

## 原型
**类型**：static（静态站）
**技术栈**：Vite + React + Tailwind CSS
**页面数**：单页应用（顶部导航切换四个视图：首页总览 / 需求报告 / 可行性分析 / 工作量分析）

## 路由表
- `/` -> 首页（项目看板概览）
- `#requirements` -> 需求报告
- `#feasibility` -> 可行性分析
- `#effort` -> 工作量分析

## 设计风格
- 珠宝行业高端调性，深色背景 + 金色/琥珀色点缀
- 卡片式布局，数据可视化（环形图、柱状图）
- 响应式适配

## 构建顺序
1. ✅ 项目结构 + 配置文件
2. ✅ 全局样式 + 设计Token
3. ✅ 布局组件
4. ✅ 页面实现
5. ✅ 验证构建
